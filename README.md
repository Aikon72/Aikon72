👨‍💻 Инженер по тестированию ПО  
Опытный специалист в области функционального тестирования веб и мобильных приложений. Основной фокус — обеспечение высокого качества продукта и оптимизация процессов тестирования для создания надежных и удобных решений.

🛠️ Технические навыки

Инструменты:
DevTools, Postman, Swagger, Fiddler, Charles Proxy, Android Studio
Jira, Git, UNIX
SQL (написание запросов, анализ данных)

Языки программирования:
Java, Python

Технологии:
REST API, SOAP

✨ Ключевые компетенции:
Планирование и выполнение тестирования (функциональное, регрессионное, интеграционное)
Анализ требований и создание тестовой документации (тест-кейсы, чек-листы, баг-репорты)
Оптимизация процессов тестирования и автоматизация рутинных задач
Навыки отладки и диагностики проблем на различных уровнях (клиент-сервер)
