**1 Ввод правильных данных**<br>
Шаги для воспроизведения:
1. Открыть https://demoqa.com/text-box
2. В поле "Full name" ввести имя кириллицей
3. В поле "Email" ввести латинскими буквами е-мейл по шаблону [почта]@[домен].com
4. В поле "Current Address" написать название любого города кириллицей
5. В поле "Permanent Address" написать название любого города кириллицей
6. Нажать кнопку "Submit"<br>
**Ожидаемый результат:**<br>
Произойдет Сабмит, данные отобразятся в отдельном окне
