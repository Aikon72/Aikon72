### 2. Напишите SQL запрос, который выведет всех покупателей, которые еще не сделали ни одного заказа.  
Предложите структуру БД для этой задачи сами — опишите её в ответе.

Для задачи подойдет простая структура из двух таблиц:

- **Таблица `customers` (покупатели):**
  - `id` (INT, PRIMARY KEY) — уникальный идентификатор покупателя.
  - `name` (VARCHAR) — имя покупателя.

- **Таблица `orders` (заказы):**
  - `id` (INT, PRIMARY KEY) — уникальный идентификатор заказа.
  - `customer_id` (INT, FOREIGN KEY) — идентификатор покупателя, который сделал заказ.
  - `order_date` (DATE) — дата заказа.

Связь между таблицами: один покупатель (`customers`) может иметь много заказов (`orders`).

**SQL-запрос:**
```sql
SELECT c.id, c.name
FROM customers c
WHERE NOT EXISTS (
    SELECT *
    FROM orders o
    WHERE o.customer_id = c.id
);
